# directives

Claude Directives (`Claude Directives/rules/`) 用の規則ファイルのコピー。claudecode.wl のディレクティブ機構を使う環境では
`Claude Directives/rules/` にそのまま置く (正本は Claude Directives 側。ここは配布用の写し)。

- `110-resonite-tablet.md` — ワールド内タブレットのプロンプトへの答え方 (ResoniteShowObject / ResoniteListGadget を提案コードとして
  実行する、Deferred は成功、検索語を core 関数に渡す、3D 生成は ResoniteGraphics3D)。
- `109-resonite-resoloop-mcp.md` (ResoLoop パッケージ側に同梱) — resoloop 経由の建築の規則。
